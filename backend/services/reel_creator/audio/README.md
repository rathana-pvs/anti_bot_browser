# Original news audio beds

These recordings were synthesized for this application by
`scripts/generate_news_audio.py`. They contain generated oscillators and seeded
noise, with no third-party recordings, stock samples, or broadcaster themes.

The project grants permission to use, copy, modify, and distribute these nine
recordings with the application and in videos created with it, without attribution.
They are provided without warranty. This permission covers these bundled files,
not music imported separately by an operator.

Format: mono PCM16 WAV at 24 kHz. The original Breaking pulse, Daily headlines,
and Politics briefing are 20 seconds. Urgent wire, Alert desk, Live update,
Developing story, Major headline, and Washington watch are 30 seconds.
Keep the `v1` files stable so saved
compositions continue to refer to the same audio. New music gets a new version.
